# 算法训练台 · C++ 刷题与可视化教学平台

> 专为系统化算法学习、面试攻坚打造的交互式教学工作台。**基于力扣算法大牛 灵茶山艾府（EndlessCheng / 灵神）经典指南《如何科学刷题？》设计**，采用“心流通道保护、LeetCode Contest Rating 难度分驱动、新手村螺旋上升、核心心法模板演化”的现代化科学刷题体系。

## 🌟 灵神《如何科学刷题？》体系化落地亮点

1. **新手村 7 阶段通关路线图（Stage 0 ~ 7）**：
   - **Stage 0 · 基础基本功**：链表与指针基础（消除指针恐惧）
   - **Stage 1 · 核心主线**：滑动窗口与双指针（定长滑窗、不定长滑窗）
   - **Stage 2 · 核心主线**：二分查找与二分答案（灵神红蓝染色法，告别死循环）
   - **Stage 3 · 基础数据结构**：前缀和与单调栈、堆与优先队列（极值与空间换时间）
   - **Stage 4 · 深入理解递归**：二叉树 DFS 基础与进阶（掌握递归三问，为 DP 奠基）
   - **Stage 5 · 网格搜索**：网格图 DFS/BFS（连通性、沉岛法与拓扑排序）
   - **Stage 6 · 树形搜索**：回溯算法（选与不选 vs 枚举选哪个 双重视角）
   - **Stage 7 · 破除DP恐惧**：动态规划入门（从记忆化搜索到递推的 1:1 三步演化法）
   - **Stage 8+ · 进阶进阶殿堂**：高阶链表、哈希进阶、并查集/Trie、贪心思维题
2. **LeetCode Contest Rating 难度分精细化量化**：
   - 每道题标有真实力扣竞赛难度分（1100 ~ 1780+），模块内题目严格按难度分升序排列，真正实现螺旋上升。
   - 提供 **「🌱 新手村 (≤1700分)」** 专项过滤器：一键过滤高分复合难题，专注单一知识点。
3. **三种科学刷题模式自由切换**：
   - **方法 A · 专题突破模式（默认）**：按知识树集中突破，建立套路肌肉记忆。
   - **方法 B · 盲盒随机实战（去标签化）**：自动隐藏算法分类与难度分，随机抽题，训练赛场与面试中判断题型的敏锐直觉。
   - **方法 C · Hot 100 突击模式**：精选 30+ 道 LeetCode Hot 100 必刷经典题，适合面试冲刺。
4. **灵神四大核心心法融入知识卡片**：
   - 二分查找：开区间红蓝染色法（区间划分原理与模板）
   - 滑动窗口：进出收缩三步法（定长 vs 不定长求最长/最短）
   - 二叉树：递归三问（当前节点做什么？何时返回？给父节点传递什么？）
   - 回溯算法：输入视角（选/不选）与答案视角（枚举选哪个）
   - 动态规划：回溯思考 $\rightarrow$ 加记忆化 $\rightarrow$ 1:1 翻译为递推数组

## 🛠️ 如何扩展与二次开发

### 1. 新增一道算法题
打开 `data/problems.js`，向 `PROBLEMS` 数组末尾添加对象：
```javascript
{
  id: 'gr4',                     // 题目唯一 ID
  mod: 'graph',                  // 归属模块 ID
  idx: 4,                        // 模块内题目序号
  title: '岛屿的最大面积',        // 题目标题
  lc: 'LeetCode 695',            // LeetCode 编号
  diff: 2,                       // 难度：1(容易) / 2(中等) / 3(困难)
  tags: ['网格搜索', 'DFS'],       // 标签列表
  by: 'return',                  // 判题依据：'return' (返回值) 或 'var:nums' (修改原数组)
  brief: '简要题意描述。',
  ioIn: '输入说明。',
  ioOut: '输出说明。',
  ex: [{ i: '[[0,1],[1,1]]', o: '3' }], // 示例输入与期望输出
  params: ['[[0,1],[1,1]]', '[[0]]'],  // 测试用例列表（管道符 | 分隔多参数）
  sig: 'int maxAreaOfIsland(vector<vector<int>>& grid)', // 函数签名
  template: 'int maxAreaOfIsland(vector<vector<int>>& grid) {\n    return 0;\n}', // 初始模板
  hints: ['提示1', '提示2', '提示3'],
  ref: [                         // 官方参考解法（每行一个字符串）
    'int maxAreaOfIsland(vector<vector<int>>& grid) {',
    '    // 代码逻辑',
    '    return 0;',
    '}'
  ],
  note: '解法核心思想说明。',
  complexity: '时间 O(m × n)，空间 O(m × n)。',
  pitfalls: ['易错点1', '易错点2']
}
```

### 2. 新增或修改模块知识卡片
打开 `data/knowledge.js`，在 `MODULE_SUMMARIES` 中配置对应模块：
```javascript
'graph': {
  title: '图 · 建模与连通性',
  concepts: ['核心思想1', '核心思想2'],
  templates: [{ name: '拓扑排序模板', code: '// C++ 模板代码' }],
  complexity: [{ op: '遍历所有点边', time: 'O(V + E)', space: 'O(V + E)' }],
  connections: '岛屿数量(200) → 课程表(207) → 省份数量(547)'
}
```

### 3. 一键打包为单文件
如果在日常维护中修改了多个 CSS、JS 或数据文件，并希望打包成一个便于分享给他人或离线拷贝的单文件，只需运行：
```bash
python build.py
```
构建工具会自动将所有代码无损压缩内联，生成 `dist/算法训练台.html` 并同步更新根目录文件。

## 🧩 作为 Chrome / Edge 扩展在力扣中直接使用

本项目已原生配置为标准的 **Chrome Manifest V3 浏览器扩展**！你可以直接将整个 `D:\CodeTeacher` 目录载入浏览器，在真实的力扣（LeetCode）网页上边刷题边享受灵神体系加持：

### 1. 三步快速安装指南
1. 打开 Chrome 或 Edge 浏览器，在地址栏输入：
   - Chrome 用户：`chrome://extensions/`
   - Edge 用户：`edge://extensions/`
2. 打开右上角的 **「开发者模式（Developer Mode）」** 开关；
3. 点击左上角的 **「加载已解压的扩展程序（Load unpacked）」**，选择目录 `D:\CodeTeacher` 即可！

### 2. 在力扣网页中获得的三大能力
1. **自动识别当前真题**：
   - 打开任意力扣题目（如 [LeetCode 162. 寻找峰值](https://leetcode.cn/problems/find-peak-element/)）；
   - 网页右上角立即浮现灵神悬浮助教胶囊，自动注入 `Rating 1510`、`🌱 新手村` 或 `🔥 Hot 100` 徽章。
2. **灵神心法随手速查**：
   - 点击浮动栏上的 **「💡 灵神心法」**，无需离开力扣，直接弹出本题所属模块的灵神核心思维与红蓝染色/滑窗模板；
   - 点击 **「📋 复制代码」** 可一键将参考解法复制进剪贴板。
3. **原生 SidePanel 侧边栏与真题无缝联动**：
   - 点击浮动栏上的 **「🚀 侧边栏」**（或浏览器右上角扩展图标），Chrome 右侧将无缝展开独立的训练台工作窗；
   - 侧边栏自动与力扣当前题目同步；
   - 点击侧边栏中的 **「🚀 在力扣打开本题」** 或 **「🎲 换一题」**，当前力扣网页将自动跳转至下一道符合心流难度的真题！
